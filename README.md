# 🛡️ BharatShield AI

### Privacy Protection for Indian Documents

BharatShield AI is an AI-powered privacy protection tool designed to detect and redact sensitive information from Indian documents and text.

## 🚀 Features

- Email address detection
- Aadhaar-like number detection
- PAN number detection
- Automatic sensitive information redaction
- Privacy Risk Score (0–100)
- Privacy summary dashboard
- Download protected text

## 💻 Technologies Used

- Python
- Streamlit
- Regular Expressions (Regex)

## 📂 Project Structure

BharatShield-AI/
- app.py
- detector.py
- redactor.py
- requirements.txt
- README.md

## ⚙️ Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder.

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python -m streamlit run app.py

## 🎯 Problem We Solve

Sensitive personal information can accidentally be exposed when sharing documents or text.

BharatShield AI helps identify and hide sensitive information before sharing.
